# boilerplate

![boiler](boiler.jpg)

Boilerplate code for the [omni-scrna](https://github.com/omni-scrna/) omnibenchmark.

- [`actions/`](actions/) — reusable GitHub Actions for modules (e.g. `validate-module`).
- [`docs/`](docs/) — module-author guides: [getting the shared code into your module](docs/common-code.md), the [shared CLI helpers](docs/cli.md), [adding CI](docs/ci.md). The stage-schema format (for benchmark authors) lives with the schemas, in the plan's [`docs/stage-schemas.md`](https://github.com/omni-scrna/split-stages-plan/blob/main/docs/stage-schemas.md).
- [`AGENTS.md`](AGENTS.md) — layout and conventions.

# boilerplate

![boiler](boiler.jpg)

Boilerplate code for the [omni-scrna](https://github.com/omni-scrna/) omnibenchmark.

- [`actions/`](actions/) — reusable GitHub Actions for modules (e.g. `validate-module`).
- [`docs/`](docs/) — module-author guides: the [shared CLI helpers](docs/cli.md), [adding CI](docs/ci.md); plus [stage interfaces](docs/stage-interfaces.md) for schema/benchmark authors.
- [`AGENTS.md`](AGENTS.md) — layout and conventions.
